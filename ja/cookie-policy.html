Cookie とブラウザー保存の方針

草案の適用日：2026年10月5日

この草案は、新しい多言語 Arotec パイロットページのブラウザー保存について説明します。言語の記憶は任意で、初期状態ではオフです。公開前に、運営者の情報と以下のサービス提供者の情報を確認する必要があります。

この草案の対象ページ

対象は、新しいホーム、Neuro-Skin Science、Co-Creation、Get In Touch、およびこの方針の各ページです。タイ語、英語、日本語、簡体字中国語、繁体字中国語の25ページに、言語選択の入口ページを加えた合計26のパイロットページを対象とします。

その他の既存ページ、会員サービス、管理者ページは、このパイロット向け方針の対象外です。旧言語切替コードは、有効期限を組み込まずに localStorage の as-site-language キーを使用します。新しいパイロットページではそのコードを読み込みませんが、以前に保存された旧キーは、利用者が消去するまでブラウザーに残る場合があります。

任意の言語記憶

このパイロットでは、明示的な言語保存の選択のために、このサイト自身の localStorage キー arotec-storage-preferences-v1 を1つ使用します。ページの表示や言語リンクの利用に、この記録は必要ありません。記録にはバージョン1、記憶のオンまたはオフ、オンの場合のみ記憶する言語、savedAt と expiresAt の時刻が含まれます。氏名、問い合わせフォームの本文、パスワード、決済カード情報は含みません。

記録は、設定の保存または記憶せずに使うことを明示的に選んだ際に初めて書き込まれます。オフの記録には記憶する言語を残さず、選択を尊重するために使用します。記憶がオンの間に通常の言語リンクをクリックして別の言語を選ぶと、記憶する言語を更新し、最大180日の新しい有効期間が始まります。ページの URL に指定された言語が常に優先されます。有効な記憶済み言語を移動先の選択に利用できるのは、言語選択の入口ページだけです。

各記録の有効期間は、最後に設定を保存した時点、または記憶がオンの状態で言語リンクから更新した時点から最大180日です。localStorage はブラウザーによって自動的に期限切れにはなりません。無効または期限切れの記録は、次に設定を確認した際に使用せず消去します。その後、任意の言語記憶はオフになります。

選択の変更と消去

「保存データの設定」から操作を再び開けます。「この言語を180日間記憶する」のチェックボックスは初期状態でオフです。「設定を保存」は明示的な選択を保存し、「記憶せずに使う」はオフの選択を保存します。通知を開く、スクロールする、閉じるだけでは記憶はオンになりません。

「記憶した言語を削除」は、言語を残さず、同じキーにオフの選択を記録します。オフの保存に失敗した場合、サイトは自身の設定キーの削除を試み、記憶がオフであることを確認します。保存にアクセスできず削除を確認できない場合は、現在のページでは記憶をオフにしますが、再読み込みやその後の訪問で以前の保存済み設定が戻る場合があります。この場合、削除やオフ選択の継続を保証できません。それ以外の場合、以後の訪問と再読み込みでは、有効な保存済みの選択または確認済みの削除を尊重します。保存がブロックされている、または利用できない場合でも、ページと言語リンクは機能します。

ブラウザーの設定からサイトの保存データを消去することもできます。この操作が管理するのは、当パイロット自身の設定記録です。他のサイトやアクセスできない第三者が保存したデータの削除は保証できません。

フォントとホスティングのリクエスト

このパイロットでは、任意のアクセス解析、マーケティング用トラッカー、埋め込みメディアを有効にしません。一部のフォントはサイト内のファイルから提供されます。Google Fonts を使用する場合、ページの読み込み時に fonts.googleapis.com と fonts.gstatic.com へフォントのリソースを要求します。提供者は、それらを配信するために IP アドレスとリクエスト情報を受け取る場合があります。フォントのリクエストは、この任意の言語保存の記録とは別です。

現在のパイロットは GitHub Pages でホストされます。ホスティングとフォントの提供者は、それぞれの条件に従ってリクエストを処理または記録する場合があります。具体的なログ、保管期間、サーバー側の Cookie の動作については、運営者の確認と実行時の検証が必要です。この草案は、サイト全体のどこにも Cookie がないと主張するものではありません。

連絡先と確認状況

既存のサイトは連絡先として arotec@arotec-group.com を掲載しています。運営者は、このアドレスが適切なプライバシー窓口であることを確認し、草案を確定する前に法人名と所在地を提示する必要があります。このアドレスへのメール到達はテストしていません。

これは実装上の事実に基づく草案であり、法令遵守を保証するものではありません。公開前に、運営者は適用される法域、法的根拠、サービス提供者との取り決め、および追加で見つかった保存について確認する必要があります。
